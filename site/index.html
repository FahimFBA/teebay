Teebay is a peer-to-peer marketplace for things that don't need a permanent home — buy what's worth keeping, rent what you'll use once, and sell what's just sitting in the garage. Built as a full-stack reference app with React, GraphQL, and PostgreSQL underneath.

Run it locally

Two servers, one database

Clone the repo, point Prisma at a local PostgreSQL database, and run the backend and frontend dev servers side by side. Full troubleshooting notes — migrations, seeding, product-ID resets — live in the README.

$ git clone https://github.com/FahimFBA/teebay.git
$ cd teebay/backend && npm install
$ npx prisma migrate dev && npm run dev
$ cd ../frontend && npm install --force
$ npm run dev
# open http://localhost:5173
